- **A browser-maps re-run no longer stops at the map viewer libraries.** unpkg answers a resume request for `maplibre-gl.js` and `pmtiles.js` with the whole file, so when they were already on the drive, `curl -C -` failed and the installer stopped with "download failed" on every re-run. Both installers now download these three small pinned files fresh each run and swap them in after the check; the old copy stays if the new one is bad. Part of #101. _[@boostedchaos](https://github.com/boostedchaos) - PR #249._
