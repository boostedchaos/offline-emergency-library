- **The phone docs pack builds on GitHub again.** From GitHub's runners, archive.org's download link often redirected to a European data node that never answered, so the "Publish phone docs pack" job timed out on a different PDF each run and the pack link stayed 404. The builder now downloads each archive.org PDF from the item's own data nodes (listed in its metadata) first, and uses the old download link only as a last try. The `sources.tsv` hash check is unchanged. _[@boostedchaos](https://github.com/boostedchaos) - PR #247._
