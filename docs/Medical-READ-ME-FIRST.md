# Medical — Offline Health & First-Aid Reference

Offline medical reference for emergencies. **Two kinds of files:**

- **PDFs** → open in **Edge or any web browser**. **No software needed.**
- **`.zim` archives** → open with **OPEN-LIBRARY** in the top folder of the drive (see
  `Kiwix-Reader/HOW-TO-USE-KIWIX`).

---

## What's here

| Folder | Read with | Contents |
|---|---|---|
| `Library/` | OPEN-LIBRARY (.zim) | Military medicine, CDC health information, NHS medicines A–Z, MedlinePlus, LibreTexts medicine, LibrePathology |
| `zimgit-medicine/` | OPEN-LIBRARY (.zim) | Curated field and emergency medicine books |
| `WikiMed/` | OPEN-LIBRARY (.zim) | Medical Wikipedia — only downloaded when full Wikipedia is skipped (full Wikipedia already contains it) |
| `Manuals-PDF/` | Browser (PDF) | Hesperian's *Where There Is No Doctor* and *Where There Is No Dentist*, one PDF per chapter, in reading order |

Also relevant: the **Army first-aid manuals** in `Manuals/ArmyFieldManuals/`.

> Hesperian's books are downloaded from Hesperian for your own use. Hesperian asks for
> permission before anyone shares them digitally, so do not copy this folder to others.

---

## Ask an AI about the PDFs

Use **GPT4All** (`AI-Offline/DocReader-GPT4All/`, see `HOW-TO-ASK-YOUR-DOCS`) and add
`Medical/Manuals-PDF` as a collection, then ask things like *"how do I treat a burn?"*
It answers from the books and cites the source. Browse the medical archives with **OPEN-LIBRARY**.

---

## ⚠️ Important

This is **reference information, not a substitute for a doctor.** Models and books can be
wrong or out of date. In a real emergency, get professional medical help whenever
possible. Use this when no help is available, and double-check anything critical.
