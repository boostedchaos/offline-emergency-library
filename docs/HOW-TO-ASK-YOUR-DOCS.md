# Ask the AI About Your Documents

The offline AI chat can **read a PDF or text file and answer questions from it**, with no
internet.

## How

1. Start the AI with **AI-CHAT** (see `HOW-TO-RUN-OFFLINE-AI`).
2. In the browser, click **+** next to the message box and choose a **PDF** or text file —
   for example a chapter from `Medical/Manuals-PDF/` or an Army manual from
   `Manuals/ArmyFieldManuals/`.
3. Ask your question, for example: *"From this chapter, how do I treat a burn?"*

The page shows **"processed as text content"** when the file was read.

## Tips

- **Attach one chapter at a time.** The AI can only hold a limited amount of text. The
  Hesperian books are already split into chapters for this reason.
- **Scanned PDFs** (pictures of pages, no selectable text) give the AI nothing to read.
  Read those yourself, or search the archives with OPEN-LIBRARY.
- The big archives (Wikipedia, medical sites, iFixit) are `.zim` files. Search them with
  **OPEN-LIBRARY**, not the AI.
- **Check the answer** against the document itself before you act on anything medical.

## Tested

On 2026-11-01 a test PDF containing a made-up code was attached in the chat; the small
model answered with the code from the PDF, and the page made no internet requests.
