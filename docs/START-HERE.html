🛟 Offline Emergency Kit — START HERE

This drive is a self-contained offline library + AI. Everything works with no internet, on Windows, macOS and Linux. This page tells you what is here and how to open each part.

The buttons you need

To do this Open this file (in the top folder)
Read the library — Wikipedia, medical, survival, repair, education OPEN-LIBRARY — .bat on Windows, .command on Mac, .sh on Linux. Your web browser opens at http://localhost:8095. Search everything there. Close the black window to stop.
See a street map — any US state OPEN-MAPS — same three versions. Opens at http://localhost:8097/viewer/.
Ask the offline AI — questions, or about a PDF you attach AI-CHAT — same three versions. Pick small (any laptop) or medium (16 GB memory). Opens at http://localhost:8098.
Check the drive — prove no file has rotted CHECK-DRIVE — same three versions. Takes 10–40 minutes.
  • PDFs and these guides (.html) open in any web browser. No software needed.
  • README.html lists every file on the drive with links.

Mac: if macOS blocks a .command file, open System Settings → Privacy & Security and click Open Anyway. Windows: if SmartScreen warns, click More info → Run anyway.

Quick start by need

  • Medical / first aid: OPEN-LIBRARY → search, or open the Where There Is No Doctor chapters in Medical/Manuals-PDF/. Army first aid: Manuals/ArmyFieldManuals/.
  • Fix something (car, appliance, plumbing, electrical): OPEN-LIBRARY → iFixit, Appropedia, DIY Q&A.
  • Water, food, shelter: OPEN-LIBRARY → survival archives; plus the Army survival PDFs.
  • Grow or cook food: OPEN-LIBRARY → gardening, cooking, homesteading.
  • Radio: Manuals/Radio-Communications/RADIO-GUIDE.html, and the ham-radio Q&A.
  • Find your way: OPEN-MAPS on a computer; the OsmAnd phone app for directions (OsmAnd/HOW-TO-VIEW-MAPS.html).
  • Chat with an AI offline: AI-Offline/HOW-TO-RUN-OFFLINE-AI.html.

Look after the drive

  • Once a year: plug it in and run CHECK-DRIVE. SSDs left without power slowly lose data; a yearly check finds damage while your second copy is still good.
  • Keep two copies in two places.
  • Store it in a media-rated safe (UL Class 125). A normal fire safe (Class 350) can get hot enough inside to ruin a drive.
  • Practice now. Open the library and the maps once, so you know how in an emergency.
  • Set up anything that needs a one-time online step (iPhone apps) now, while you have internet.

⚠️ Reminders

  • Offline AIs and old manuals can be wrong. Check anything safety-critical.
  • This is reference information, not a substitute for a doctor or a professional.
